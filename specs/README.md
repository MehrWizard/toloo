# Toloo Protocol Specification v0.2

This directory contains the normative Toloo protocol specification (RFC
documents). The implementation lives in the same repository: `toloo-core`,
`toloo-lib`, `toloo-cli`, `toloo-app`, `toloo-web`, and `toloo-wasm` at the
project root.

Status: Draft
Version: 0.2

Return to the [project README](../README.md).

## Conventions
All normative keywords follow RFC 2119 / RFC 8174. See `0-index.md`.

## Implementation Note
The spec is the source of truth. When code and spec diverge, update the code to
match the spec.
